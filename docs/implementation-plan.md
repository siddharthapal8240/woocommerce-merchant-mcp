# Assignment delivery milestones

Branch: `feat/woocommerce-connector`. Custom implementation: TypeScript only.

1. **Connector foundation:** strict TypeScript, environment validation, WooCommerce GET client, six MCP tools, schema validation, pagination, safe errors, bounded retries, automated tests, CI.
2. **Real local store:** start WordPress/WooCommerce, generate restricted API credentials, seed fictional orders/products with TypeScript, verify successful authentication and API responses.
3. **End-to-end demonstration:** exercise the connector through an MCP client, export tool specifications, demonstrate merchant questions with an agent, verify error cases against the live setup.
4. **Submission:** complete setup instructions, capabilities/limitations, design rationale and test evidence; review secrets and repository accessibility; prepare application link.

Milestone 1 is the first implementation checkpoint. Milestones 2–4 must not be called complete based solely on synthetic-response tests. Agent Studio compatibility remains unverified until its access/transport requirements are available.
